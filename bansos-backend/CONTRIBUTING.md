# Contributing to BansosHub Backend

1. Pastikan coding style mengikuti standar PSR-12 via Laravel Pint:
   ```bash
   composer lint
   composer format
   ```
2. Pastikan seluruh feature & unit test lulus:
   ```bash
   php artisan test
   ```
3. Gunakan format commit: `feat: ...`, `fix: ...`, `test: ...`, `refactor: ...`.
4. Dilarang commit berkas `.env` atau credential asli.

# Contributing to BansosHub Frontend

1. Jalankan linter ESLint dan pastikan 0 error/warning:
   ```bash
   npm run lint
   ```
2. Jalankan formatter Prettier:
   ```bash
   npm run format
   ```
3. Pastikan build production berhasil tanpa kendala:
   ```bash
   npm run build
   ```
4. Gunakan format commit: `feat: ...`, `fix: ...`, `refactor: ...`.
